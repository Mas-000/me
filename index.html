地端危機偵測引擎
一句話進來，不連網判斷要不要驚動家人。

L0沒事，不處理
L1記下來，不打擾任何人
L2通知家人，手機立刻收到
做得到　純規則 5,359 行，只用 Python 內建的 re，不連網、不用 GPU，一句 2 毫秒
做不到　婉轉、整句沒有危險字的（「我東西都整理好了」）規則層抓不到。完整系統（規則＋LLM）在外部臨床量表出的題目上約四成六

信用違約預測
Kaggle 15 萬筆，正樣本只有 6.7%。
四個模型混合，Private AUC 0.86946。
做法　自建 25 個特徵 → XGBoost／LightGBM／CatBoost／自寫的 TabResNet → 5-fold 交叉驗證 → 用 OOF 搜出混合權重
為什麼看 AUC 不看 F1　F1 要先訂一個門檻，門檻變了分數就變； AUC 不用訂門檻，衡量的是「把會違約的排在前面」的能力
實驗紀錄 · 打叉的比打勾多
  • ✓v4 基準　OOF 0.86740 → Private 0.86946
  • ✗Pseudo-label　偽正例率 51%，分佈偏移
  • ✗多加 7 個特徵　樹模型不需要手工交互
  • ✗加寬神經網路　寬度無助益
  • ✗加深神經網路　OOF 虛高，Private 退步
  • ✗Stacking meta-model　不如直接 grid blend
這張表才是重點　上面每一個 ✗ 都是標準教科書做法、也是任何人會建議我試的。 我試了，然後用數據一個一個否決掉。
特別是「加深網路：OOF 虛高、Private 退步」——本地分數變好、換一份沒看過的資料就退步。 那跟我在危機偵測上量到的是同一件事。
